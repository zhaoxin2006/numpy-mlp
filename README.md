# NNDL 全连接神经网络 MNIST 图像分类

本项目为 NNDL 理论课程作业 **A1：全连接网络** 的实现，使用 NumPy
从零实现多层全连接神经网络（MLP），完成 MNIST
手写数字图像分类，并围绕网络结构、学习率、损失函数、正则化方式以及优化算法开展对比实验。

项目不调用深度学习框架完成分类，而是手工实现神经网络训练过程中的核心组成，包括：

-   数据集读取、归一化与训练/验证/测试集划分
-   全连接层前向传播
-   ReLU 激活函数
-   Softmax 与数值稳定处理
-   交叉熵、MSE + Softmax、SVM Hinge Loss
-   反向传播与梯度计算
-   L1 / L2 正则化
-   Dropout
-   SGD、Momentum、AdaGrad、RMSProp、Adam、AdaMax
-   Mini-batch、Online GD、Batch GD
-   验证集模型选择与 Early Stopping
-   数值梯度检查
-   实验结果保存与训练曲线绘制

## 3. 数据集

项目使用 MNIST 手写数字数据集。

每张图像大小为：

``` text
28 × 28 = 784
```

因此网络输入维度为 784，输出类别为 10，对应数字 `0~9`。

数据预处理主要包括：

1.  将像素值转换为 `float32`
2.  将像素值缩放到 `[0, 1]`
3.  使用固定随机种子 `42` 打乱数据
4.  按照以下方式划分数据：

  数据集         样本数量
  ------------ ----------
  Training         50,000
  Validation       10,000
  Test             10,000

运行：

``` bash
python "data.py"
```

运行完成后会生成：

``` text
mnist_split.npz
```

其中包含：

``` text
X_train, y_train
X_val, y_val
```

## 4. 网络结构

项目使用多层感知机（MLP）完成分类。

基本结构为：

``` text
输入层
  ↓
全连接层
  ↓
ReLU
  ↓
全连接层
  ↓
Softmax / 分类损失
```

实验中主要比较了以下结构：

``` text
784 → 128 → 10
784 → 256 → 10
784 → 256 → 128 → 10
```

权重采用 He 初始化：

``` text
W ~ N(0, sqrt(2 / fan_in))
```

偏置初始化为 0。

隐藏层使用 ReLU，输出层直接产生 logits，再交给对应损失函数处理。

------------------------------------------------------------------------

## 5. 前向传播

对于第 `l` 层：

``` text
Z(l) = A(l-1) W(l) + b(l)
```

隐藏层使用 ReLU：

``` text
A(l) = max(0, Z(l))
```

输出层不直接使用激活函数，而是输出 logits。

对于交叉熵损失，logits 会经过数值稳定的 Softmax 得到类别概率。

为了避免指数运算产生数值溢出，Softmax 实现中首先减去每个样本的最大
logit：

``` text
exp(z_i - max(z))
```

------------------------------------------------------------------------

## 6. 反向传播

反向传播根据链式法则逐层计算梯度。

输出层首先计算损失关于 logits 的梯度，然后依次向隐藏层传播。

对于全连接层：

``` text
dW = A_prev.T @ dZ
db = sum(dZ)
```

对于 ReLU：

``` text
dZ = dA * I(Z > 0)
```

Dropout 在训练阶段保存随机掩码，并在反向传播时使用相同掩码传播梯度。

------------------------------------------------------------------------

## 7. 损失函数

项目实现了三种分类损失。

### 7.1 Cross Entropy

交叉熵与 Softmax 配合使用：

``` text
L = -1/N Σ log(p_y)
```

对应的 logits 梯度可以直接写为：

``` text
dZ = (P - Y) / N
```

这是项目中的主要分类损失。

### 7.2 MSE + Softmax

首先将标签转换为 one-hot
向量，然后计算预测概率与目标概率之间的均方误差。

该方法用于与交叉熵进行对比。

### 7.3 Multiclass SVM Hinge Loss

采用多分类 Hinge Loss：

``` text
L = max(0, score_j - score_y + 1)
```

用于比较不同损失函数对训练效果的影响。

------------------------------------------------------------------------

## 8. 正则化

项目实现了 L1、L2 和 Dropout 三种正则化方法。

### L2 正则化

目标函数中加入：

``` text
λ / 2 * Σ W²
```

对应梯度增加：

``` text
λW
```

实验使用：

``` text
λ = 1e-4
λ = 1e-3
```

### L1 正则化

目标函数中加入：

``` text
λ * Σ |W|
```

梯度中加入：

``` text
λ * sign(W)
```

实验使用：

``` text
λ = 1e-5
```

### Dropout

实验中使用：

``` text
dropout = 0.2
```

训练阶段随机丢弃部分隐藏层神经元，并采用 inverted dropout
保持激活值期望基本不变。

## 10. Batch / Online / Mini-batch

项目还比较了不同的数据批处理方式。

### Batch GD

一次使用全部 50,000 个训练样本计算梯度。

``` text
batch_size = 50000
```

### Online GD

每次只使用一个样本。

``` text
batch_size = 1
```

### Mini-batch SGD

每次使用一个小批量样本。

``` text
batch_size = 64
```

实际实验中 Mini-batch 是主要训练方式。

## 11. 训练流程

训练函数的基本流程如下：

``` text
初始化网络参数
      ↓
随机打乱训练集
      ↓
划分 Mini-batch
      ↓
前向传播
      ↓
计算损失
      ↓
反向传播
      ↓
加入正则化梯度
      ↓
优化器更新参数
      ↓
计算 Train / Validation 指标
      ↓
根据 Validation Loss 保存最佳模型
      ↓
Early Stopping（可选）
      ↓
恢复最佳模型
      ↓
在 Test Set 上评估
```

训练过程中每个 epoch 会记录：

-   train loss
-   train accuracy
-   validation loss
-   validation accuracy

实验结果同时保存最佳验证集指标和测试集指标。

------------------------------------------------------------------------

## 12. 模型选择与 Early Stopping

训练代码使用 **Validation Loss 最小值**
作为最佳模型选择标准，而不是直接根据测试集结果选择模型。

当启用 Early Stopping 时：

``` text
patience = 10
```

如果验证集损失连续 10 个 epoch 没有改善，则提前停止训练。

停止后恢复验证集损失最低时保存的模型参数。

这样可以避免单纯选择最后一个 epoch 所导致的模型性能下降。

------------------------------------------------------------------------

## 13. 梯度检查

项目提供 `grad_check.py` 对反向传播实现进行数值验证。

测试使用一个较小的网络：

``` text
10 → 5 → 3
```

采用有限差分计算数值梯度：

``` text
∂L/∂θ ≈ [L(θ + ε) - L(θ - ε)] / (2ε)
```

其中：

``` text
ε = 1e-4
```

再将数值梯度与反向传播得到的解析梯度进行比较。

该过程用于验证手工实现的反向传播是否正确。

运行：

``` bash
python "grad_check.py"
```

## 19. 项目特点

本项目的主要特点是将一个完整的神经网络训练流程拆解为若干独立模块，并使用
NumPy 手工完成核心算法。

从数据输入到最终分类结果，完整流程为：

``` text
MNIST
  ↓
数据归一化
  ↓
784维输入
  ↓
MLP
  ↓
前向传播
  ↓
Loss
  ↓
反向传播
  ↓
Gradient
  ↓
Optimizer
  ↓
Parameter Update
  ↓
Validation Model Selection
  ↓
Test Evaluation
```

因此该项目不仅用于获得 MNIST
分类结果，也用于验证全连接神经网络中前向传播、反向传播、损失函数、正则化以及参数优化之间的完整关系。
